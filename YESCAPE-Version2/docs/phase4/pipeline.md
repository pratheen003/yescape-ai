# Verification Pipeline Documentation

---

## Overview

The Verification Pipeline is the central execution engine of YEScape.

It receives an internship offer and executes all verification signals sequentially before producing a final trust score and risk verdict.

The pipeline guarantees that every signal executes independently and that a failure in one signal will not stop the remaining verification process.

## Components

### Verification Engine

Responsible for

- coordinating every signal
- handling failures
- collecting signal results
- generating VerificationResult

Location

core/verification_engine.py

---

### Signal Factory

Creates all verification modules.

Location

core/signal_factory.py

Responsibilities

- instantiate all signals
- avoid duplicate initialization
- provide a centralized signal registry

---

### Score Fusion

Responsible for combining all signal scores into one final trust score.

Location

core/fusion/score_fusion.py

Outputs

- Final Score
- Risk Level
- Confidence
- Reasons

---

### Verification Result

Stores

- Final Score
- Risk Level
- Confidence
- Reasons
- Individual Signal Results

Location

schemas/verification_result.py

## Error Handling

Every signal executes through

safe_execute()

which returns

(success, result)

instead of allowing exceptions to terminate the verification process.

If one signal fails

↓

Remaining signals continue

↓

Final report is still generated
